# 포트폴리오 점수 문구 수정안 (문서만 · HTML 수정 안 함)

작성: 2026-10-16 KST · 상태: **사용자 검토 대기**. `portfolio/report.html` 등 페이지 파일은 바꾸지 않았다.

## 1. 왜 고쳐야 하나

2026-10-15 사람 대조에서, P2 채점이 **A2 5점**을 준 TC에 범위 변경의 필수 시험 3가지가 빠져 있었다(냉방 31°C 차단 없음, 20°C 적용 기대결과 없음, 모드 전환 질문 없음 — [IMP-009](../../improvements/IMP-009-range-change-rules.md)). 또 10-15 실행에서 채점 20개 중 19개가 5점이었다(점수 포화, [IMP-008](../../improvements/IMP-008-output-cap-and-log-truncation.md)).

그래서 지금 페이지의 "각 5.0", "모두 5점"은 읽는 사람에게 **"AI 결과가 사람 기준으로도 완벽했다"**로 읽힐 수 있지만, 실제로는 **"초안 채점 기준으로 AI 채점기가 감점하지 않았다"**는 뜻에 가깝다.

예: 시험지에 100점이 적혀 있어도 채점표가 문제 일부를 빠뜨렸다면, "100점"보다 "채점표 기준 감점 없음(채점표 보완 중)"이 정확하다.

## 3. 바꾸지 않을 것

- 점수 숫자 자체(과거 결과는 다시 매기지 않음 — 작업 규칙).
- "제품 불일치를 찾아낸 것을 에이전트 실패로 보지 않음" 같은 판정 원칙 문장.
- 사례별 평균을 하나로 합치지 않는다는 설명(66행).

## 4. 결정이 필요한 것

1. 위 수정안대로 페이지를 고칠지, 일부만 고칠지(예: 42행 안내문과 80행 칩만).
2. 새 문단에 range-oracle 결과(FAIL 3/6)를 넣을지 — 이 수치는 PC 저장 자료 재검사 결과이며 클라우드에서는 원본을 다시 확인하지 못했다.
3. 수정 시점: 다음 실제 실행(규칙 반영 후 재평가) 결과를 본 뒤 한 번에 고칠지, 지금 문구만 먼저 고칠지. **권장: 지금 문구만 먼저**(점수 의미 오해는 지금도 생기므로).
