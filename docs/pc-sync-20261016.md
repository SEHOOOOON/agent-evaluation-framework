## 2. 받아오기 (그 자리에서 갱신)

PowerShell 기준이다.

**P1** (예상 결과 `bf02cf5`)
```powershell
git pull --ff-only origin claude/fixes-20261015
git log --oneline -3
```

**P2** (예상 결과: 맨 위가 이 문서를 추가한 커밋, 그 바로 아래가 `2bf1471`)
클라우드 작업은 `claude/fixes-20261015-u58dgi` 브랜치에 있다. `f71814b` 바로 뒤에 쌓았으므로 fast-forward로 받아진다.
```powershell
git fetch origin claude/fixes-20261015-u58dgi
git merge --ff-only FETCH_HEAD
git log --oneline -15
```
`--ff-only`가 실패하면(PC에 다른 커밋이 있으면) 합치지 말고 멈춰서 보고한다.

되돌리기가 필요하면 `git switch -c backup-before-pull <이전 커밋>`처럼 이전 커밋으로 새 브랜치를 만들어 확인한다. 이전 상태는 커밋 번호로 언제든 다시 열 수 있다.

## 6. B안(예상된 제품 불일치) 확인

같은 Run 폴더(5번에서 찾은 P1 Run 폴더, 압축이면 푼 폴더)로 실행한다.

```powershell
$env:PYTHONPATH = "src"
python -c "import json; from pathlib import Path; from eval_harness.execution_observations import grade_run; from eval_harness.product_expectations import ExpectedMismatch, classify; obs={}; g=grade_run(Path(r'<P1 Run 폴더>'), observations=obs); print('A3-03', g['verdict'], g['reason']); print(json.dumps(classify([ExpectedMismatch(field='setTemp', expected=20, actual=19, reason='제품 미변경')], obs, g['verdict']), ensure_ascii=False, indent=2))"
```

기대: `A3-03 PASS`, 결과 `AS_EXPECTED`. 냉방 감소 후 패널·카드·내부값 3곳이 `where`에 나와야 한다.

다르면 그대로 보여 준다.
- `UNVERIFIED`면 A3-03이 왜 PASS가 아닌지 보고한다.
- `NOT_AS_EXPECTED`면 `unexpected` 목록을 보고한다.
