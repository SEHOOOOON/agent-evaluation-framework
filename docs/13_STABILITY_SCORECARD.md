## 2026-10-04 · 최신 코드의 등록 후 재사용 로컬 확인

실제 저장 전원·중풍 결과를 현재 제품 사본에서 재시험하고, 시험용으로 등록한 동일 TC·코드를 다음 실행 목록에서 읽어 재실행·복원까지 확인했다. 보류·미등록은 자산을 유지하고 필요한 SRS 개정 동의가 없으면 등록을 차단했다. 기존 TC 대체는 별도 공통 회귀검사이며 이 저장 자료 재사용 결과에 포함하지 않는다.

이것은 새 AI 전체 실행이나 26항목 재평가가 아니다. 공식 자산과 과거 점수는 그대로이며 아래 과거 70건에 합산하지 않는다. 새 결과의 범위·해시는 [로컬 확인 요약](../portfolio/local-verification.json), 전체 검사·자료 누락·미검증 상태는 [현재 인계](../PROJECT_HANDOFF.md)에 기록했다. 원본은 P1 바깥 작업공간 `runs/c1004/summary.json`이다.

### Agent 3 지적의 원문 대조

### 마무리 판단과 다음 작업

평가표 정리는 완료했으나 반복 안정성·오차단율·정확도 측정까지 완료한 것은 아니다. 새 규칙·AI 호출은 추가하지 않았다. 다음 최소 작업은 사람이 이 평가표와 공식 등록 시연 필요 여부를 확인하는 것이다. 자산관리 전체 연결을 포폴에서 완료로 주장하려면 별도 승인 아래 승인 전후 변경 및 후속 재사용 증거가 필요하다. 이미 등록된 MED를 촬영을 위해 취소하거나 다시 신규 등록하지 않는다. 그 전에는 확인된 시험·복원·보고 범위만 설명한다. 커밋·푸시와 추가 실행은 별도 지시 후 진행한다.

## 평가 구분과 진행 조건

- 저장 Run 진단: 과거 자료의 구조·근거 연결 확인. 새 모델 정확도·반복 안정성으로 계산하지 않는다.
- 정식 평가: P1/P2 소스·프롬프트·요청·SRS·TC·제품·기준 버전 고정 후 실행한다.
- 정답은 실행 전 사람이 필수 조건·허용 결과·기대 분기를 확인한다. 사후 작성 기준은 DRAFT로 표시한다.
- PASS / FAIL / 미검증 / 해당 없음 / 평가기 오류를 구분한다. 실행되지 않은 Agent를 PASS로 처리하지 않는다.
- 공식 승인·외부 게시·유료 호출·커밋은 별도 승인 범위다. 기존 승인 예산을 재사용하지 않는다.

### 후속 보완 · 2026-09-29

아래 1차 진단은 당시 기록으로 보존한다. 이후 P1 계약을 대조해 P2 인용 검사·A3 적용 안내·A4 실행 전체 근거 부족 연결을 보완했다. [IMP-005](../improvements/IMP-005-p1-contract-compatibility.md)에 변경과 검증을 기록했다.

새 검사로 저장 전원·풍량·환경 점검 전용 Run을 읽은 결과는 각각 자동 검사 23·23·19 PASS, 종합 REVIEW다. 원본 해시 불변이며 정식 고정 버전 평가나 실제 API 재실행이 아니다. 의미 정확도·반복 안정성은 여전히 미검증이다.

정식 run-v2는 P1 추적 파일 변경 시 버전 고정을 요구한다. 현재 .env 로딩 보완 등이 미커밋이므로 정식 실행을 완료했다고 표시하지 않는다.
저장 Run에 evaluate 함수를 직접 적용하는 진단은 정식 runner의 대체가 아니며, 승인된 새 모델 실행·품질 점수·안정화 완료의 근거로 사용하지 않는다.
이번 조사는 기존 변경과 원본 Run을 보존하며 외부 네트워크를 차단한다.
