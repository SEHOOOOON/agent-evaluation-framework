## 5. 저장 자료 재검사 (API 없음)

대상: `evaluation-runs\live-20261015\runs\FLOW-20261015-110607-bb73a2`. 원본 해시를 기록해 두고, 끝난 뒤 다시 확인해 같아야 한다.

### 5-1. range-oracle 1.2 (T-5 질문 판정 엄격화)

지난번처럼 `trial-1\evidence.zip`을 임시 폴더에 풀어 실제 `agent2_test_design.json`, `agent1_change_analysis.json`을 대조한다.

```powershell
python -m eval_harness range-oracle --key benchmarks\v2\range_keys\representative-temperature.json --design <임시>\p1\runs\RUN-20261015-110609-8E2600\agent2_test_design.json --analysis <임시>\p1\runs\RUN-20261015-110609-8E2600\agent1_change_analysis.json
```

예상: `verdict: FAIL`, 필수 3/6. `T-5:QUESTION:COOL`은 `MISSING`(1.1과 같음. 실제 TC에 질문이 없으므로). A1·A2 문장 중 "냉방"만 들어간 질문이 있으면 `PARTIAL`이 나올 수 있다. 그때는 해당 문장을 보고한다.

### 5-2. rejudge-flow 미리보기 (호출 없음)

```powershell
python -m eval_harness rejudge-flow --flow evaluation-runs\live-20261015\runs\FLOW-20261015-110607-bb73a2 --trial 1 --roles A3 A4
```

예상:
- `roles.A3`, `roles.A4`가 `READY`이고 `payload_bytes`가 500,000 이하
- `maximum_api_attempts: 2`, `approval_sha256` 출력
- FLOW 폴더 파일이 바뀌지 않음
- 실행 후 `qaf-rejudge-*` 폴더가 남지 않음

`BLOCKED`나 오류가 나면 메시지를 그대로 보고한다. **`--execute`는 실행하지 않는다**(유료 호출).

### 5-3. P1 사람 최종 검토서 재생성 비교

원본 Run을 직접 고치지 않도록, 5-1에서 푼 임시 폴더의 `p1\runs`를 대상으로 한다. 임시 폴더의 기존 `사람_최종_검토.md`, `사람_최종_검토_manifest.json`을 다른 이름으로 옮긴 뒤 새로 생성한다.

```powershell
python <P1>\src\qa_pipeline_orchestrator.py human-review --runs-root <임시>\p1\runs --run-id RUN-20261015-110609-8E2600
```

(명령 이름과 인자는 `--help`로 먼저 확인한다.)

예상: 냉방 TC 항목에 `#### 기대 결과별 관찰 (QA_ASSERTION_OBSERVED)`가 생긴다.
- ER-004~006(30°C)은 "관찰 기록상 통과 (관찰값 30)"
- 냉방 감소 ER(기대 20)은 "관찰 기록상 불일치 (관찰값 19)"
- 관찰 기록이 없는 ER만 "개별 판정이 확인되지 않습니다"

기존 문서와의 차이는 이 부분뿐이어야 한다. 다른 줄이 바뀌면 멈추고 보고한다.
