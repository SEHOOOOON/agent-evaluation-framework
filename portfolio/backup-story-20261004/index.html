01 / 평가 설계

한 번의 PASS보다,
무엇을 확인했는지가 중요합니다.

제품이 정상인지와 Agent가 제 역할을 했는지는 다른 질문입니다.
제품의 문제를 정확히 찾아 FAIL로 보고했다면, 그 역할은 잘 수행한 것입니다.

A1

요구사항을 정확히 읽었나?

변경할 값과 유지할 조건을 구분하고, 없는 정보를 만들어내지 않았는지 봅니다.

분석 결과 ↔ 요청 · SRS
A2

시험할 내용을 잘 설계했나?

기존 TC 재사용, 조작 순서, 기대결과와 복원에 필요한 내용이 빠지지 않았는지 봅니다.

TC ↔ 요구사항 · 작성 기준
A3

TC대로 실제로 확인했나?

정해진 대상·값·시점대로 시험하고, 원래 상태로 복원한 증거가 있는지 봅니다.

실행 정의 ↔ 코드 · 실행 기록
A4

결과를 정확히 설명했나?

실행 수량과 실패 이유를 바르게 보고하고, 미실행·확인 부족을 숨기지 않는지 봅니다.

규칙 기반 보고 ↔ 실제 결과
단계 사이도 확인

조건·출처의 전달, 잘못된 결과의 통과와 정상 결과의 반려, 사람 승인 경계를 함께 평가합니다.

당시 역할 고유 항목의 평가 점수. 공통·전체 연결은 별도입니다.
평가 역할채점 범위원본 평균 / 5함께 읽어야 할 내용

역할 고유 항목 18개 + 공통 항목 1개 = 총 19개 채점. 공통·전체 연결 항목은 아래 26항목에 포함됩니다. 5점은 기준 충족, 4점은 경미한 부족, 0~3점은 중요한 미충족을 뜻합니다.

좋은 점수도 그대로 믿지는 않았습니다.

A3의 ‘복원 확인 누락’ 반려는 원문 대조에서 오반려로 확인했습니다. A2의 ‘해당 없음’ 판정도 적용 판단 오류가 남아 있습니다. 위 점수는 당시 원본이며 최신 성적·정확도·완성도가 아닙니다.

70번의 AI 전체 실행이 아닙니다.

제품 시험은 시나리오별 1회, 총 10회입니다. 각 실행 증거를 7개의 독립 승인 사본에서 재사용했습니다. TC는 저장 AI 산출물 1종과 로컬 참고 TC 9종이며, 앞 단계 출처 확인 일부는 시험 대역을 사용했습니다.

7개 경로에서 확인한 것 펼치기
  1. 보류 — 사유를 남기고 SRS·공식 TC는 유지합니다.
  2. 미동의 차단 — SRS 개정 제안에 동의하지 않은 승인은 막습니다.
  3. 동의 후 승인 — 대상 SRS와 후보 TC·자동화가 시험 목록에 반영됩니다.
  4. 보류 후 승인 — 보류 기록을 보존하고 이후 승인을 처리합니다.
  5. 중복 방지 — 다시 승인해도 같은 TC를 중복 등록하지 않습니다.
  6. SRS 충돌 차단 — 검토 이후 바뀐 SRS를 덮어쓰지 않습니다.
  7. 저장 오류 복구 — 오류를 주입한 뒤 변경 파일이 이전 상태로 돌아오는지 확인합니다.

운영 승인·저장·복구 함수 사용. 실제 공식 자산은 변경하지 않았습니다. 70회 UI 클릭, 동시 승인, 프로세스 중단·전원 단절 복구까지 확인한 결과는 아닙니다.

CASE 01 / P1 처리 개선해당 항목 개선 확인

이미 있는 요구사항을 다시 수정하라고 했습니다.

현재 SRS와 같은 문장을 수정안으로 제안해, 필요 없는 승인과 단계 차단이 발생했습니다.

수정 전

검증 요청에도 개정안을 요구

‘개정안이 필요하다’는 규칙과 ‘같은 문장은 수정이 아니다’라는 검사가 충돌했습니다.

수정 후

문서 변경과 시험 필요를 분리

이미 반영된 기준은 불필요하게 고치지 않고, 실제 기준 변경에 필요한 개정과 승인은 유지했습니다.

재확인

같은 요청의 새 AI 응답에서 불필요한 수정안이 사라졌습니다. 전체 흐름은 다른 조건 연결 문제로 중단돼, 해당 개선과 별도 이슈로 나눠 기록했습니다.

2026.09.20 · IMP-001 · P2가 실행·수집한 P1 검사 차단과 후속 코드 검토로 발견. 별도 평가 AI가 독립 검출한 사례는 아닙니다.

CASE 02 / 평가 입력 개선원본 판정 보존

복원 확인은 있었지만, 평가 AI는 없다고 봤습니다.

원문·코드·실행 기록에는 복원 비교가 있었습니다. 평가 입력의 축약 참조를 AI가 명세 누락으로 해석했습니다.

수정 전 · 기준 2.2

3 / 5 복원 명세 누락으로 반려

압축된 참조 표현을 제대로 읽지 못한 평가였습니다. P1의 복원 기능을 삭제하거나 기대값을 낮추지 않았습니다.

재평가 · 기준 2.3

5 / 5 기존 복원 명세 인정

직접 비교하는 원문을 그대로 전달하고 검토 책임을 명확히 했습니다. 같은 P1 자료의 재평가 1회에서 통과했습니다.

배운 점

평가 점수도 증거와 대조해야 합니다. 두 점수는 평가 조건이 달라 P1 성능 향상률로 계산하지 않으며, 기존 3점 판정을 덮어쓰지 않았습니다.

2026.10.02 · IMP-004 · TC·계획·코드·로그 불변. 다양한 반례와 반복 평가 정확도까지 검증한 결과는 아닙니다.
