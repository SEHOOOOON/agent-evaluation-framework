이 점수는 저장 당시 결과입니다. 일부 평가자 오판이 확인돼 현재 완성도·정확도로 해석하지 않습니다. 변경된 기준의 재평가 점수는 합치지 않았습니다.

역할별 점수와 평가 기준

역할을 펼치고 항목을 선택하면 세부 기준·원본 판단 근거를 볼 수 있습니다.

Agent 고유 20개 + 공통 2개 + 전체 연결 4개 = 26개. 평균은 해당 역할에서 채점된 항목만 계산하며 공통 항목을 중복 합산하지 않습니다.

5점 척도와 평가 방법

점수 읽는 법

5점
필수 기준 전체를 근거로 확인
4점
핵심 충족, 영향 없는 경미한 설명 부족
3점
핵심 일부 충족, 중요한 누락 있음
2점
주요 조건 여러 개 누락·불일치
1점
핵심 대부분 미충족
0점
핵심 목적에 반하거나 수행 범위 전체 불충족

4~5점은 통과, 0~3점은 반려입니다. 미평가·해당 없음에는 점수를 만들지 않습니다.

누가 평가하나요?

파이썬은 수량·값·증거 연결 같은 사실을, AI는 요구사항과 산출물의 의미를 대조합니다. 혼합 항목은 두 근거를 함께 봅니다.

현재 담당: 파이썬 3개 · AI 12개 · 혼합 11개. 담당 정의가 26개 전체 자동 채점을 뜻하지는 않습니다. 평가자의 오판은 별도로 검토합니다.

항목 안의 세부 기준은 현재 2.4입니다. 위 원본 점수는 당시 2.2 결과이며, 현재 기준으로 다시 평가한 점수가 아닙니다.

시나리오별 확인 결과

‘일치’는 승인·보류·차단 등이 예상한 대로 처리됐다는 뜻입니다.

시나리오보류동의 안 함승인보류 후 승인중복 등록SRS 변경등록 실패
7개 경로에서 확인한 내용
  • 보류 / 동의 안 함: 공식 자산 변경 없음
  • 승인 / 보류 후 승인: 유효한 승인으로 등록
  • 중복 등록: 같은 항목을 중복 등록하지 않음
  • SRS 변경: 검토 이후 기준이 바뀌었으면 그대로 등록하지 않음
  • 등록 실패: 중간 오류 시 일부만 반영된 상태를 남기지 않음

실제 사용자 승인 화면을 70번 클릭한 결과는 아닙니다. 동시 처리·프로세스 강제 종료·전원 장애까지 확인한 것은 아닙니다. Agent 26항목 점수와 별도 검사입니다.

개선 기록

SRS에 이미 있는 내용을 수정안으로 다시 제안 응답 1건 개선 확인

수정 전: 기존 SRS와 동일한 문장을 새 수정안으로 제출했습니다.

수정 후: P1의 작성 지침·개정 검사를 보완했습니다. 실제 새 응답 1건에서 해당 중복 제안이 사라졌지만 전체 흐름은 다른 문제로 중단됐습니다.

발견 근거: P2가 수집한 P1 Checkpoint 차단과 후속 코드 검토. AI 평가자가 독립적으로 검출한 사례로 표시하지 않습니다. 기록: IMP-001.

복원 확인이 있는데 없다고 평가 별도 재평가 확인

수정 전: A3-01은 복원 확인 누락을 이유로 3점을 받았습니다. 원본 명세·코드·로그를 대조하니 복원 비교가 있었습니다.

수정 후: 평가 입력·기준을 보완한 별도 재평가에서 5점을 받았습니다. 같은 P1 산출물이며 원본 3점은 그대로 보존했습니다.

기준 2.2 → 2.3으로 평가 조건이 다릅니다. P1 성능 향상이나 같은 조건 반복 안정성을 뜻하지 않습니다. 기록: IMP-004, 2026.10.02.
