# IMP-002 · 복합 조건과 기존 TC의 연결 누락

- 상태: **실제 응답의 연결·CP2 및 재사용 실행·CP4 통과 1건 / 별도 Judge 평가 미완료**
- 발견일: 2026-09-20 / 대상: Agent 1 조건 구성·Agent 2 재사용 근거 연결 / CP2-019
- 발견 실행: [FLOW-20260920-091635-adc771](../evaluation-runs/FLOW-20260920-091635-adc771/result.json).
- 증거: [A1 패킷](../evaluation-runs/FLOW-20260920-091635-adc771/trial-1/A1/packet.json), [A2 초안 패킷](../evaluation-runs/FLOW-20260920-091635-adc771/trial-1/A2/packet.json), 원본 trial-1/evidence.zip.
- 검출 주체: P2 실행 중 P1 CP2-019 차단, 이후 코드·산출물 대조. 별도 AI Judge 판정 아님.

## 1. 쉽게 설명하면

‘중풍 표시와 강풍 표시를 확인한다’는 하나의 조건이 있습니다. 중풍 TC와 강풍 TC를 모두 선택했지만, 이 복합 조건의 근거 연결은 중풍 TC에만 붙었습니다. 강풍 TC는 별도의 강풍 전용 조건에만 연결됐습니다.

따라서 선택 목록에는 두 TC가 있어도, 해당 복합 조건만 따라가면 중풍 검증밖에 찾을 수 없습니다. 검사기는 누락된 HIGH 근거를 지적했습니다.

## 2. 확인한 원인

- A1의 COND-011·COND-012에는 MED와 HIGH가 함께 들어 있습니다. 개별 MED 조건과 HIGH 유지 조건도 별도로 생성됐습니다.
- A2는 TC-V2-002에 COND-011·012를 연결하고 TC-V2-001에는 COND-015만 연결했습니다.
- CP2-019는 조건별로 연결된 기존 TC들의 검증 동작을 합쳐 코드·수치를 비교합니다. 여러 TC가 한 조건을 나누어 검증하는 것은 이미 허용합니다. ‘한 TC에 모든 검사를 강제하는 규칙’으로 단정하거나 검사를 완화할 이유는 확인되지 않았습니다.
- 읽기 전용 진단으로 메모리에서 HIGH TC에도 COND-011·012 연결을 추가하면 새 CP2 전체가 PASS였습니다. 원본 초안·CP2·실행 기록은 변경하지 않았습니다. 이는 AI 재작성이나 제품 실행 결과가 아닙니다.

## 3. 제안하는 수정 방향

1. A1이 원문 근거를 유지하면서 변경·유지 조건을 구분하는 안내를 점검합니다. 이미 개별 조건이 있는데 복합 요약을 별도 검사 의무로 중복 생성하는지도 검토합니다.
2. A2에 복합 조건을 선택한 여러 TC가 나누어 검증한다면 관련 TC 모두에 같은 조건 ID를 연결하도록 안내합니다. TC를 선택한 것과 조건에 연결한 것을 구분합니다.
3. CP2 피드백에 빠진 값·현재 연결된 TC를 명확히 안내하는 방안을 검토합니다. 관계 없는 TC를 자동 연결하거나 기대값 검사를 삭제하지 않습니다.
4. 한 TC로 충분한 조건, 두 TC로 나뉜 조건, 한쪽 값의 실제 미검증을 각각 반례로 검증합니다. 이후 별도 승인한 실제 실행으로 확인합니다.

위 목록은 최초 수정안입니다. 후속 사용자 승인에 따라 아래 범위만 적용했습니다. 같은 실행에서 A1 최초 응답의 단일 장비 사전조건 누락도 재발했으나 허용된 1회 재작성으로 보완됐습니다.

## 적용한 보완

- Agent 2 최초 입력에 조건별 코드·수치, 재작성에는 연결된 기존 TC ID·그 연결로 미충족인 값·담당 신규 후보를 표시합니다. 원본 조건·TC는 변경하지 않는 진단입니다.
- 하나의 조건을 여러 TC가 나누어 검증하면 각 담당 TC에 같은 조건 ID를 연결하도록 안내합니다. 다른 조건에만 연결한 TC는 현재 조건의 근거가 되지 않습니다.
- 추출 값만으로 자동 추천·연결·의미 합격을 결정하지 않습니다. 빈 추출 값도 검증 불필요가 아닙니다. 대상·조작·판정·복원을 기존 명세와 대조해야 합니다.
- CP2 판정 함수는 기존 커밋과 AST 동일합니다. 검사 완화·기대값 변경·자동 연결을 넣지 않았으며 과거 실패 기록은 그대로입니다. Agent 1의 유효한 복합 조건도 처리할 수 있도록 Agent 2 책임을 보완했고 A1은 수정하지 않았습니다.
- 프롬프트 2.28 → 2.29, 기존 인계 3.4/SRS 개정 1.1 유지. 관련 테스트 133건 및 전체 515건 통과·실패/오류/Skip 0건: [JUnit](../../qa-agent-pipeline-v2/runs/manual_checks/imp002-20260920.xml). 추가 fixture의 ID 형식 오류를 수정한 뒤 재검사했습니다. 풍량·온도·모드 12조합과 입력/진단 2개를 추가했습니다.
- 보완 소스는 812ebf983c5fa7c2a32368969684b67e7d848917로 로컬 커밋했습니다. 실제 재평가 FLOW-20260920-093653-329153은 이 버전을 사용합니다. 과거 b4c4749 실행과 소급 혼합하지 않습니다.
